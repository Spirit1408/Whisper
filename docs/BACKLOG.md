## M0-B — Immediate Safety

**Цель пакета** — защитить текущие сценарии до появления SQLite. Зависит от A. Основные файлы — `src/main.py`, `transcriber.py`, `postprocessor.py`, `lmstudio.py`, `text_inserter.py`, `audio_recorder.py`, `gui.py`, `config.py` и при необходимости `history.py` внутри `src/`.

| ID | Предлагаемое изменение | Acceptance criteria |
|---|---|---|
| B1 | Убрать тексты STT/LLM из новых INFO/DEBUG-записей. Ограничить сообщения исключений, тела HTTP, stderr CLI и подробность логов библиотек. Оставить коды причин, длительности, размеры и состояния. | По синтетической метке проверены успех и отказ Raw/Smart. Ни метки, ни промпта, ни содержимого буфера в новых логах или диагностике нет. Старые файлы не переписываются. |
| B2 | Убрать `unload_other_llms` из пути смены модели. Различить доступность сервера и готовность выбранной LLM. При загрузке по разрешённой политике использовать только известный локальный ресурс. | Запись вызовов CLI показывает отсутствие выгрузки чужого/неясного экземпляра при успехе, ошибке и нехватке памяти. Raw доступен без LM Studio. |
| B3 | Загружать STT из локального пути/кэша без сетевой проверки. Разрешать только локальный endpoint для обычного inference, учитывать redirects и proxy. При отсутствии весов или внешнем адресе сообщать причину. Загрузку не инициировать автоматически. | В изолированной среде с запретом внешнего соединения локальный путь доступен. При отсутствии весов, внешнем endpoint, redirect или внешнем proxy пользовательский текст не выходит во внешнюю сеть. |
| B4 | Вставлять только при проверенных условиях. При смене/неопределённости цели, защищённом поле, сложном буфере или отсутствии проверенного профиля оставить видимый результат и явный Copy. Если безопасный способ ещё не подтверждён, пометить автодоставку пропущенной. | B5 | Для устранения отказов аудио и текущего Smart проверять тип `content` и признак завершения, сохранять доступный raw при сбое, показывать исход и приводить статус и микрофон в согласованное состояние при ошибке старта/выходе. | `null`, пустой и обрезанный ответ, недоступная LLM и ошибка микрофона не оставляют ложный успех или вечный Listening. На `eb38861` повторно прошли 60/60 автоматических тестов. Владелец подтвердил полный ручной сценарий в отдельном профиле Windows, включая физический PTT, Smart, ручной Copy и сохранность обеих версий после перезапуска. [Условия и протокол](TESTING.md)
