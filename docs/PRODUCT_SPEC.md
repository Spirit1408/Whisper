# Product Vision и спецификация

**Утверждено как целевое состояние.** Local AI Input Workspace — самостоятельное desktop-приложение для Windows 11. Пользователь диктует или выбирает текст, получает доступный локально исходник и, по желанию, обработанный результат в том приложении, где работает. Обычная диктовка требует одного жеста. При неопределённости доставки текст остаётся доступен в Workspace.

Сегодня из исходников работает Local Dictation с PTT, Faster Whisper, необязательной корректурой LM Studio, редактируемым полем, JSON-историей и треем. Инструкция — в [README](../README.md). Ниже задано целевое поведение. Границы релизов определены в [Roadmap](ROADMAP.md).

## Пользовательские сценарии и критерии

| ID | Сценарий | Наблюдаемое требование |
|---|---|---|
| P01 | Raw Dictation | PTT → речь → отпускание → STT → сохранённый Original. LLM не вызывается. При подтверждённых условиях допускается доставка в выбранное поле. Toggle-to-Talk добавляется в M5. |
| P02 | Smart Dictation | Та же диктовка с локальной корректурой. Original доступен до вызова LLM. Валидный результат сохранён до доставки. Ошибка видна, разрешённый fallback использует сохранённый Original. Существующий Smart поддерживается во время перехода. |
| P03 | Четыре источника | Голос, выделение в стороннем приложении, явное чтение буфера и встроенный редактор создают артефакт. Текстовые источники фиксируются в момент команды. Для выделения используется UIA, проверенный clipboard fallback доступен в совместимых профилях. |
| P04 | Повтор и ручная правка | Пользователь выбирает Original или текущий результат. На артефакт приходится один текущий результат каждого пресета. Ошибка, отмена и поздний ответ сохраняют предыдущую успешную версию и ручную правку. |
| P05 | История | По умолчанию нет лимита числа текстовых записей в пределах диска. Есть поиск, избранное, экспорт выбранного текста, настраиваемая политика удаления и корзина с начальным сроком 30 дней. Доступна ручная очистка по действию пользователя. |
| P06 | Доставка | Действия — автоматическая вставка, явное копирование, сохранение в артефакт. Глобальные настройки, пресет и профиль приложения участвуют в решении. Смена адресата или выделения, неизвестное или защищённое поле и неподдерживаемый буфер исключают автовставку. UI различает отправку вставки и подтверждение поля. |
| P07 | Workspace | PySide6, единые цвета, типографика и компоненты, три панели со сворачиваемыми боковыми секциями, светлая, тёмная и системная темы. Компактный overlay показывает состояние и огибающую реального микрофона, сохраняет позицию с учётом мониторов и DPI, оставляет фокус получателю. |
| P08 | Команды и доступность | Постоянный активный пресет, Command Palette по командам, пресетам, артефактам и настройкам, выбор пресета для одного вызова и индивидуальные hotkeys. Системный трей, уведомления, настраиваемые звуки и глобальные клавиши. Диагностика сообщает о внутренних коллизиях и отказе регистрации ОС. |
| P09 | Языки | Языки UI — английский, русский, украинский и бразильский португальский. Язык UI, фиксированный или автоматически определяемый язык STT и целевой язык перевода задаются независимо. |
| P10 | Ресурсы и поставка | Faster Whisper и LM Studio со сменными адаптерами. Начальный профиль Balanced. Встроенное состояние моделей и диагностика доступных RAM/VRAM, независимый benchmark. Папка с EXE и runtime запускается без системного Python. Для Raw требуются локальные STT-веса, для Smart дополнительно доступная локальная LLM. |

## Семантика пресетов

| Пресет | Что должен получить пользователь |
|---|---|
| Raw | Без редакции. Текст STT или снимок текстового источника. |
| Smart Strict | Корректура с сохранением языка, чисел, имён, отрицаний, намерения и формы вопроса. Модель не отвечает на продиктованный вопрос. |
| Smart Natural / Smart Professional | В Natural допустимо сглаживание устной речи, в Professional — смена регистра и стиля. Числа и факты сохраняются. |
| Prompt Engineer | Переформулированный текст запроса, доступный для просмотра и копирования. |
| Translator | Перевод на явно выбранный язык. |
| Formatter | Структурированный текст с сохранением содержания. |
| Task Extractor | Текстовый перечень извлечённых задач. |
| Summarizer | Краткое изложение по содержанию входа. |

M1c стабилизирует существующую корректуру. Система встроенных и пользовательских пресетов, редактор, версионированный валидируемый JSON-импорт/экспорт относятся к M2. Глобальная LLM и тайм-аут могут переопределяться пресетом в пределах политики приложения. Импорт не даёт внешних сетевых разрешений. Любой вывод LLM рассматривается как текст. Для корректуры допустим видимый fallback к Raw. Для специализированных преобразований предлагаемый дефолт — сохранить и сообщить о сбое без отправки исходника.

## Приватность и границы продукта

- Local-first, offline-first, privacy-first действуют и при первом запуске. При отсутствии локального ресурса приложение сообщает, что требуется. Внешняя операция требует разрешения пользователя.
- Постоянно сохраняются только необходимые текстовые артефакты и настройки. Очередь, PCM, контекст окон, выделение и промежуточные вычисления находятся в RAM. В технических журналах допустимы только минимальные метаданные. Политика диагностики описана в [архитектуре](ARCHITECTURE.md).
- Профили приложений создаются вручную и активируются по проверенной идентичности получателя. Автоматическая доставка ограничена матрицей совместимости. При достаточной уверенности доступна замена выделения, иначе предпросмотр или сохранение. Enter, Send и выполнение команд не входят в доставку.
- За границами текущего продукта остаются агентская платформа Jarvis, MCP Server, внешние Local API и CLI, плагины, облачные провайдеры, wake word, streaming STT, параллельный inference пользовательских задач, мобильные клиенты, синхронизация, установщик и автообновление. Будущим интеграциям оставлены внутренние прикладные контракты.
