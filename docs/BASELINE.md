## Состав и происхождение

[Явный список](../baseline/files.txt) содержит 34 файла, включая сам список. Работоспособный набор — все 13 модулей `src/`, оба launcher-файла, штатный `config.yaml` и `requirements.txt`. Дополнительно включены [фиксация версий](../requirements-baseline.txt), документация и средства проверки. Архив повторяет этот список и добавляет служебный `SHA256SUMS` с хешами каждого файла. Сам ZIP, его контрольная сумма и восстановленная копия находятся за пределами Git.

Идентификатор приложения и окружения вычислен по 18 файлам: 13 модулей, два launcher-файла, `config.yaml` и оба requirements-файла. Для каждого взят SHA-256 фактических байтов. В порядке `baseline/files.txt` строки `<нижний hex>  <относительный путь>` соединены LF, включая конечный LF, в UTF-8 без BOM. SHA-256 этого списка — `560c22658d9c50a3a9f6e5db94278ed859f7d75b335dce1c42eaa3de4da85616`. Итоговый ZIP имеет отдельный SHA-256 в отчёте о передаче. Изменения документации и Git-нормализация переводов строк могут менять контрольные суммы, поэтому для побайтового возврата используется проверенная копия ZIP.

**Проверка данных.** В комплекте только явно выбранные текстовые файлы. `.git`, `.venv`, кэши, веса, логи, пользовательские JSON, локальные заметки, бинарные зависимости и абсолютные пути профиля исключены. `config.yaml` уже входит в HEAD и сохранён побайтно. **Результат A3.** Один новый пример в `src/postprocessor.py` (строка 33) дословно совпал с двумя событиями существующего локального журнала. 21 ноября владелец подтвердил, что это намеренно публичный синтетический пример, и разрешил его включение в будущий состав коммита. Исключение относится только к этому примеру. Полный исходный модуль сохраняется побайтно. Других дословных совпадений по проверенным данным и признаков секретов по применённым правилам не обнаружено.

## Восстановление

1. Взять архив `M0-A-560c22658d9c.zip` из каталога `Whisper-baselines` рядом с существующим checkout и доверенный полный SHA-256 из отчёта M0-A. Соседний файл `.sha256` позволяет перепроверять целостность локальной копии. При несоответствии остановиться.
2. Из checkout выполнить следующий PowerShell-блок, подставив SHA-256 из отчёта. Каталог назначения создаётся заново рядом с репозиторием либо во временном каталоге. [Сценарий восстановления](../baseline/restore.ps1) отказывает при существующей цели и при попытке распаковки внутри исходного checkout.
3. Проверить сообщение `PASS restore` по всем 34 файлам. Из восстановленного дерева выполнить smoke проектным интерпретатором. Он ещё раз копирует исходники в краткоживущую песочницу, чтобы обе истории, настройки и диагностический файл оставались изолированными даже при повторной проверке.

```powershell
$archive = Join-Path (Split-Path -Parent $PWD.Path) 'Whisper-baselines/M0-A-560c22658d9c.zip'
$expected = Read-Host 'SHA-256 из отчёта M0-A'
$copy = Join-Path ([IO.Path]::GetTempPath()) ('whisper-restore-' + [guid]::NewGuid().ToString('N'))
& ./baseline/restore.ps1 -Archive $archive -ExpectedSHA256 $expected -Destination $copy
if (-not $?) { throw 'Restore failed' }
& ./.venv/Scripts/python.exe -I -B (Join-Path $copy 'baseline/smoke.py')
if ($LASTEXITCODE -ne 0) { throw 'Smoke failed' }
```

Без исходного checkout доверенный ZIP после проверки его полного SHA-256 можно открыть в новом пустом каталоге и сверить файлы с `SHA256SUMS`. На этом хосте smoke использует уже установленную venv. Для полноценного запуска из копии launcher-скрипты ожидают собственную `.venv/Scripts/python.exe` и `pythonw.exe`. На новой машине нужны совместимые Windows, драйвер, Python, подготовленные установочные файлы точно зафиксированных версий, локальные веса и при необходимости LM Studio. Если позднее будет разрешена установка и предоставлен полный локальный wheelhouse, pip может использовать `--no-index --find-links <wheelhouse> -r requirements-baseline.txt`. Полный автономный набор wheels, установка с нуля и перенос лицензий/весов в этом пакете не проверялись.

## Граница проверенного

- Все 13 исходных модулей проходят синтаксический разбор и импортируются из изолированной копии. Оба launcher-файла сохраняются побайтно, их пути к проектному Python и `src/main.py` проверяются. Обычные BAT/VBS интерактивно не запускались.
- [Smoke](../baseline/smoke.py) использует реальный координатор, Transcriber с подставным backend, PostProcessor, механизм вставки с заменёнными вызовами ОС, offscreen Qt и запись/чтение временного JSON. Raw даёт одну доставку без вызова LLM. Smart даёт один HTTP-вызов-заглушку и одну доставку отредактированного результата. Проверяются обе карточки и восстановление подставного буфера. Новые логи приложения открываются только во временной копии.
- Настоящие микрофон, keyboard hook, системный буфер, HTTP-сервис, GPU-инференс и предельные сценарии не испытаны. Дефекты предыдущего аудита сохраняются для M0-B/C. Модель для продукта будет выбрана по benchmark в M3.
- Baseline-коммит `e645213ed43764240fc31a8a3074c078d4b2ddcc` содержит 20 изменений относительно `109ae70`. Проверен аннотированный тег `baseline-pre-evolution` и его целевой коммит. Smoke выше предназначен для восстановленного дерева M0-A. Текущая версия проверяется по [протоколу M0](M0-RESULTS.md).
